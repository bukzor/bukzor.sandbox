# bukzor.sandbox -- the rationale

What the design set aside, and what it assumes, kept beside the rungs it
explains. Nothing in `design.kb/` cites this collection, so deleting it
leaves the design whole; the arrows run from here into the rungs.

Three theories, one per reason a claim is not on a rung: it was
refused (`declined`), it is a fact the design leans on without arguing
(`background`), or it is held but nothing needs it yet (`deferred`).
