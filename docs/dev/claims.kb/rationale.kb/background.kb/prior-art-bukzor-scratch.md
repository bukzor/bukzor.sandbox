# Prior art: bukzor/scratch

`bukzor/scratch` is the earlier iteration of this idea: one repo, one
directory per topic, described in its README as "a versioned
scratchpad" and "an island for misfit toys". Its one stated policy is
that anything worthwhile migrates out to its own repo.

This parent differs in that every sandbox is its own repo from the
start, so migrating out is a rename rather than an extraction
(`../../design.kb/goals.kb/graduation-is-a-rename.md`).
