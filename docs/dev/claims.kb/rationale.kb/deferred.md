# Deferred

Claims the design holds, decided or proposed, that nothing needs yet in
order to use the tool: the GitHub copy of the hierarchy, the verbs that
walk the set, the open questions, and how the tooling ships. Each keeps
its own standing and `todo:`. One returns to `design.kb/` under its
rung, with its arrows, when something wants it.
