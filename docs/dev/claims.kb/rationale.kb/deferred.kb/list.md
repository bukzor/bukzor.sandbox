# list

Would print the sandboxes and their hierarchy. Whether it is a verb
of its own is undecided.

> [!QUESTION]
> The record is a directory tree of small files, so `ls -R` and
> `cat` already list it. Settled by living with those first; a verb
> is warranted only if a listing wants something they cannot show,
> such as frontmatter fields in columns. The operator's own
> uncertainty: "list? -- a nice listing? perhaps ls or cat will do
> as well though."
