# Does every sandbox carry a GitHub topic?

> [!QUESTION]
> Undecided. If yes, every sandbox carries the GitHub topic `sandbox`
> and `gh repo list --topic sandbox` indexes the set in the views that
> flatten every repo. Membership on GitHub's side is already
> `SANDBOX_SUBPATH` (`../design.kb/architecture.kb/hierarchy-on-github.md`),
> which those views do not show; the topic would add only that
> visibility. An answer settles whether `create` applies the topic and
> whether graduation removes it. The user is not sold; what would move
> them is on neither side of the record yet.
