# update

Would pull every clone forward to its remote. Whether it is a verb of
its own is undecided.

> [!QUESTION]
> It earns a verb only if it also clones every record that has no
> checkout yet, which is what a fresh checkout of the parent needs;
> otherwise it is `foreach` with `git pull` and the policy against
> wrapping applies. The operator's own uncertainty: "update? -- bring
> all up to date -- less sure about this one."
