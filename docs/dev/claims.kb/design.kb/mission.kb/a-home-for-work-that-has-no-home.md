# A home for work that has no home

This repo is the parent of throwaway work: toy designs, prototypes,
experiments. Under it, starting a sandbox costs nothing, throwing one
away needs no ceremony, and every sandbox is findable from one place.

The beneficiary is the operator and the agents working for them, who
need to begin an experiment cheaply and find it again later.
