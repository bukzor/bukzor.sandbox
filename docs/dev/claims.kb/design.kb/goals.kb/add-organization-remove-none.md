# The parent adds organization and removes none

The parent sits alongside the name-prefix convention (`prototype.*`,
`research.*`, `ideation.*`, `scratch.*`) that organizes the flat
`~/repo/github.com/bukzor/` directory. It adds an ancestor, shared
documentation, and meta-tooling; the prefixes stay as they are.

The prefixes keep working where no parent reaches: `gh repo list` and
the GitHub owner page flatten every repo, and there a prefix is the
only organization available.
