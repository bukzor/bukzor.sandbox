# An agent working in any sandbox reads the parent's documentation

Documentation that applies to every sandbox is written once, in the
parent, and reaches an agent working inside any sandbox without that
sandbox carrying a copy. The mission names the absence of shared
documentation as part of the problem; this goal is its remedy.

How the documentation reaches the sandbox is an architecture matter
(`../architecture.kb/parent-docs-by-nesting.md`).
